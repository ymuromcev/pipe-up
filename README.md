# Pipe Up

**Say it. Your Mac does it.**

A macOS menu-bar app: hold one key and talk, and your words appear wherever you're typing. Hold it together with the right ⌘ and say what you need done — your own Claude Code does it, and the answer pops up over the window you're in.

Apple Silicon · macOS 26 or later

**Install** — paste this in Terminal:

```
curl -fsSL https://raw.githubusercontent.com/ymuromcev/pipe-up/main/install.sh | bash
```

Or download the `.dmg` from the [latest release](../../releases/latest).
